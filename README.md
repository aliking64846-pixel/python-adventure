# رحلة بايثون — نسخة محلية بدون سيرفر أو قاعدة بيانات

هذه النسخة تشغّل واجهة اللعبة مباشرةً كملفات ثابتة، وتخزّن الحسابات والتقدم والإعدادات في `localStorage` داخل المتصفح.

## التشغيل محلياً

1. نزّل المشروع من GitHub بصيغة ZIP وفك الضغط.
2. افتح مجلد `frontend` داخل المشروع.
3. شغّل خادماً ثابتاً بسيطاً باستخدام Python:

   ```bash
   python -m http.server 8000
   ```

4. افتح `http://localhost:8000` في المتصفح.

هذا خادم ملفات ثابت فقط لتقديم HTML/CSS/JavaScript؛ لا يحتاج Node.js أو PostgreSQL أو قاعدة بيانات.

## حفظ البيانات

- التسجيل والدخول والتقدم والإنجازات محفوظة على نفس المتصفح والجهاز.
- مسح بيانات الموقع أو استخدام متصفح/جهاز آخر يعني أن البيانات المحلية لن تكون متاحة هناك.
- الحسابات المحلية للتجربة فقط؛ لا تستخدم كلمات مرور حساسة لأن بيانات المتصفح ليست مخزناً آمناً.
- المحادثات تعمل فقط بين الحسابات المحلية الموجودة في نفس المتصفح.

## ملفات المشروع

- `frontend/`: ملفات الواجهة واللعبة والتصميم.
- `frontend/js/core/api.js`: طبقة توافق محلية تستخدم `localStorage` بدلاً من API الخادم.
